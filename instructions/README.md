# Project Instructions

Start with [`project_conventions/directory.json`](project_conventions/directory.json)
to find the guidance relevant to a task. Permanent conventions live under
`project_conventions/`. `progress_state.json` is a temporary resume point for
active work; completed plans are archived under `completed_tasks/`.

When creating or editing project guidance, follow
[`project_conventions/documentation_guidelines.md`](project_conventions/documentation_guidelines.md).

See [`project-template-options.md`](project-template-options.md) for the
pre-generated-project decision and scaffold-generation tradeoffs.
